# dsh-report-studio 商业化方案

> 原则:开源核心永不收费,付费只加"省事"层。凭据/哈希/基础模板永远免费。

## 一句话商业模式

**开源插件免费获客 → 省时间的增值付费(模板包/发布适配/企业定制)→ Sponsors 打赏托底。**

## 变现路径(按启动顺序)

### 1. GitHub Sponsors(已就绪)

- FUNDING.yml 已指向 ciceroyang;README 里已埋"省下写日报的时间,请一杯咖啡"。
- 动作:在 GitHub 账号设置里开启 Sponsors(用户侧一键操作);
  首月把赞助金额设 5 美元/月档,后续按 star 数调档。

### 2. 付费模板包(核心收入,3 个月内上线)

开源版 4 套模板免费;付费包卖"拿来即用的专业模板 + 发布适配":

| 档位 | 内容 | 建议定价 |
|---|---|---|
| 单模板 | 如"团队晨会日报(钉钉/飞书风格)" | 9.9 元 |
| 行业全家桶 | 开发/运营/自媒体 三套 × 4 类模板 + 周报多会话聚合 | 49 元 |
| 企业定制 | 品牌模板 + 发布管道(飞书文档/Notion/公众号)定制 | 500 元起 |

交付:模板文件 + cordis 配置片段,通过微信/知识星球/爱发电销售,仓库里留指引。
路线图对齐:多会话聚合周报先做免费开源(反哺声量),云发布适配进付费包。

### 3. 企业服务(6 个月后,按项目)

帮工作室/小团队落地"DSH + 汇报流水线":安装、模板体系、凭据审计习惯、
与现有 IM(飞书/企微)打通。按天/按项目报价,客单 2000-20000 元。

### 4. 内容流量(并行,0 成本)

- 教程《从零到发布:给 DeepSeek Harness 写你的第一个插件》已写好(docs/tutorial-zh.md),
  分发到掘金 / 知乎 / 公众号 / V2EX。
- 每篇尾部导流:repo + Sponsors + 模板包预告。
- 攒粉后接课程/社群会员(定价 99-199 元/年)。

## 关键指标

- 冷启动目标(30 天):repo 30 star、5 installs、1 个真实用户反馈
- 验证指标(90 天):100 star、20 installs、模板包 10 单
- 里程碑:进 awesome 列表(PR 已开)→ 官方 Discussions 教程帖 → 掘金首页

## 风险与对策

- Harness 预览期接口变动 → 插件纯 ESM 免构建,跟进成本低;教程同步更新
- 市场教育成本(很多人不知道 dsh)→ 内容先行,教程即广告
- 大厂复制 → 先发优势 + 中文办公模板积累 + 凭据链差异化
